# 路书

个人用的活路书。说一句去哪儿，就出一份可改的结构化草稿；路上用三个按钮只改今天。不代订，不收款。

模型密钥只放在浏览器里。请求发出时带给服务器，用完即弃，不写入路书，也不写日志。

## 本地运行

```bash
pnpm install
cp .env.example .env
pnpm dev
```

打开 [http://127.0.0.1:3847](http://127.0.0.1:3847)。

```bash
pnpm eval        # 离线结构检查，含路书补丁 / 撤销 / 三按钮
pnpm typecheck
```

## 模型密钥（只在浏览器）

首页或路书页点「填写模型密钥」。

| 项 | 建议 |
| --- | --- |
| 接口 | `https://api.deepseek.com/v1`（任何 OpenAI 兼容接口都可以） |
| 模型 | `deepseek-chat` |
| 存放 | 这台浏览器的 localStorage |

不填也能出本地草稿。密钥通过请求头交给当次调用，服务器不用 `LLM_API_KEY` 写新路书。`.env` 里的 `LLM_API_KEY` 只留给旧的双方案流程和 `pnpm eval:live`。

搜索仍用服务器上的 Tavily / Brave 密钥（可选）。天气用 Open-Meteo，不需要密钥。像「去西湖走走」这种句子会先解析成杭州再查天气，不会把整句当地名。

## 访问密码和私密链接

每本路书有一条不可猜测的链接：`/b/<id>/<密钥>`。没有这条链接，别人打不开。

没设密码时，服务器**不列出**全部路书。首页只显示这台浏览器生成过的链接。部署到别人能访问的机器之前，请设置：

```bash
ACCESS_PASSWORD=一长串只有你知道的密码
AUTH_SECRET=另一长串随机字符串
```

设了以后：

1. 首页先输入密码，才能新建，也能在手机上看到同一份列表。
2. 把私密链接发到自己的手机，不输入密码也能打开这一本。
3. 没有密码、也没有链接的人，看不到路书。

这不是邮箱验证码。旧的邮箱登录还留在 `/login`，只给以前的双方案记录用。

## 怎么用

1. 首页写一句，例如「这周末想去西湖走走，两个人」，生成草稿。
2. 缺的天数、人数、出发地会变成假设标签。点标签就能改。认不出城市时，只追问一次「去哪座城市」。
3. 手机上路书是全屏，底部是输入条和三个按钮。状态是一行小字，没有步骤条。窗口变宽以后，左边是对话（原句和每一次补丁），右边仍是同一份路书；三个按钮留在路书下面。手机上不出现左栏。
4. 点一项上的「锁定」，之后的重排不会动它。
5. 底部可以写「删除河坊街」「锁定西湖」「把午饭改到 13:00」。更自由的句子需要浏览器里的模型密钥。

## 三个按钮

只改**今天、未完成、未锁定**的项。行程日期不含今天时，按第 1 天试算，状态行会写明。最近一次补丁改过的项是琥珀色，标「刚改」，路书顶部会列出刚改和刚拿掉的名字；改过的假设标签同样标「刚改」。点「撤销」后这些高亮会清掉。

| 按钮 | 做什么 | 离线 |
| --- | --- | --- |
| 晚了 1 小时 | 浏览器里用规则顺延。排到 21:30 以后就按优先级砍，自由活动和休息先砍，锁定和必去留下 | 可以。断网后仍能点 |
| 下雨了 | 向服务器要天气，户外景点改室内。锁定的户外留下，并写进核实清单 | 按钮变成「联网后可用」 |
| 累了 | 删掉未锁定的闲逛，缩短景点，插入休息 | 按钮变成「联网后可用」 |

验证可以这样做：

1. 生成西湖草稿，点「晚了 1 小时」，看开始时间后移，晚上的「可砍的夜走」被拿掉，点「撤销」恢复。
2. 先锁定「西湖」，再点「晚了 1 小时」，西湖的时间不动。
3. 浏览器开发者工具里选 Offline，再点「晚了 1 小时」，路书仍会变；「下雨了」「累了」是灰的。
4. 恢复联网后点「下雨了」，未锁定的户外景点换成博物馆一类室内项。

## 离线与主屏幕

路书页可以「添加到主屏幕」（需要 HTTPS；本机 localhost 也可以）。

打开过的路书会记在这台浏览器里，天气写在同一份文档中。服务工作线程会缓存这一页和当天的路书接口。已经打开的页面断网后，「晚了 1 小时」在本地计算；重新联网后补丁会同步回服务器。

## 部署

自用可以放在海外，不必先备案。本仓库给了一个 Docker 跑法：

```bash
docker build -t lushu .
docker run --name lushu -p 3847:3847 \
  -e ACCESS_PASSWORD='换成你的密码' \
  -e AUTH_SECRET='换成另一串随机值' \
  -e SEARCH_PROVIDER=auto \
  -e TAVILY_API_KEY='可选' \
  -v lushu-data:/app/data \
  lushu
```

不要把模型密钥放进容器环境变量。数据在卷里的 `/app/data`（路书 JSON）。前面加一层 HTTPS（Caddy、Cloudflare Tunnel 或平台自带证书）后，手机才能稳定安装 PWA。

不用 Docker 时，在服务器上：

```bash
pnpm install --frozen-lockfile
pnpm build
ACCESS_PASSWORD='...' AUTH_SECRET='...' pnpm start
```

`pnpm start` 监听 `0.0.0.0:3847`。

## 不做（留给后面）

- 不代订、不收款、不保存证件或银行卡。
- 只读分享和长图。
- 可信度的完整界面。出发前清单现在只是几行占位，不能逐条勾选。
- 风格切换，以及逐项改文案、拖时间。现在能点的是假设标签、锁定、一句话补丁和三个按钮。
- 完整邮箱验证码、12306、多端复杂同步、多城出境、免密钥额度。

桌面分栏不需要额外配置。部署仍是上面的 Docker 或 `pnpm build && pnpm start`，数据在 `/app/data`。

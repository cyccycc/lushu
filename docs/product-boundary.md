# Product boundary

路书 is a personal web travel planner for one owner. It is not a company product, not a travel agency, and not a store.

## What it does

- Takes one sentence, usually in Chinese, and writes a structured draft.
- Shows assumption tags for anything it inferred. Asks at most one question.
- Rearranges today with three buttons. Late-by-one-hour runs in the browser.
- Stores the roadbook on the server behind a secret link, and optionally one password.
- Keeps the model key in the browser. The server sees it only for that request.
- May call web search and a weather forecast. A West Lake sentence is queried as Hangzhou.
- The older two-plan pages are still on this machine for earlier sessions.

## What it does not do

- No billing. The owner pays the model provider directly. End users are not charged.
- No phone login. The only account step is an email code and a session cookie.
- No booking, checkout, payment, ticket issuance, or hotel hold. Hotel and taxi follow-ups are comparisons and route notes.
- No WeChat mini program. The product is this website.
- No invented booking links. A URL is shown only when a search or weather tool returned that exact URL, and it is plain text, not a payment button.
- No collection of passport numbers, card numbers, or other payment data.

## How to read an itinerary

Hours, prices, and crowd levels change. The page says so. A budget note is an estimate with assumptions, not a quote. Confirm anything important before leaving.
